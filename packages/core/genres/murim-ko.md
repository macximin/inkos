## 장르의 중심

문파, 세가, 강호의 위계와 명분은 실제 행동과 승패로 드러난다. 무공은 이름과 경지 설명보다 주인공에게 열린 선택, 상대의 유능한 대응, 목격자의 평판 변화, 복수와 권한의 지급으로 증명한다. 정파, 사파, 마교, 회귀, 관무의 관계는 현재 Book의 spine과 reference binding으로 구체화한다.

## 대결과 지급

- 초식은 전투 상황, 거리, 부상, 병기와 상대의 대응을 바꾸는 기능으로 쓴다.
- 강자는 갑자기 무능해지지 않는다. 정보, 체면, 제자, 문파, 생존과 이익에 맞춰 대응한다.
- 지급은 승패, 비급, 영약, 병기, 복수, 배분권, 문파 지위, 강호 평판과 두려움으로 확인한다.
- 모욕과 원한을 쌓았다면 당사자와 목격자가 무엇을 보았고 관계의 위계가 어떻게 뒤집혔는지 결산한다.
- 압도적 회귀자, 기연, 독식과 즉시 승리가 작품의 약속이면 허용한다. 성공을 벌주려고 주화입마, 수명, 죄책감이나 도덕적 대가를 발명하지 않는다.

## 강호 정합성

- 이동 거리, 소식 전파, 문파 관계, 무공의 확정 범위와 부상 상태가 현재 행동과 충돌하는지만 엄격히 본다.
- 암살, 협박, 약탈, 배신, 복수, 사파와 마교의 승리는 허구의 사건으로 허용한다. 불법과 잔혹함 자체를 creative failure로 만들지 않는다.
- Book hard rule이 정한 협의나 각성, 수위가 있으면 그대로 지킨다.

## 한국어 문체

- 한자어와 무공명은 장면의 속도와 의미를 살릴 만큼만 쓴다.
- 기세와 살기를 추상 선언하지 말고 누가 물러났고 검로가 어떻게 막혔으며 무엇을 내놓았는지 보여 준다.
- 승부 뒤 모두가 감탄했다는 설명 대신 지위, 복종, 거래와 다음 표적의 변화로 닫는다.

## 실패 조건

- 확정된 무공·거리·부상·정보 인과를 무시한 해결
- 상대와 조연의 확정된 욕망·정보·능력 붕괴
- 승패와 지급을 보여 주지 않은 경지 상승 선언
- Book에 없는 응보, 반성, 사과, 갱생, 속죄의 강제 추가
