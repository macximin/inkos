## 장르의 중심

현대의 회사, 직업, 자산, 계약, 기술, 제도와 평판이 주인공의 반복 행동에 직접 연결돼야 한다. 능력은 설명이나 상태창 문구보다 더 큰 선택, 더 어려운 저항, 더 선명한 결과로 증명한다. 재벌, 헌터, 연예계, 스포츠 같은 하위 소재는 하나의 평균으로 섞지 않고 현재 Book의 spine과 reference binding으로 구체화한다.

## 장면과 보상

- 주인공은 알고 있다는 사실보다 실제 주문, 협상, 이동, 투자, 훈련, 제작, 공개 같은 동사로 판을 바꾼다.
- 상대는 자기 정보와 이해관계 안에서 유능하게 대응한다. 주인공의 승리를 위해 욕망·정보·능력을 버리지 않는다.
- 보상은 돈, 소유권, 성과, 직위, 접근권, 평판, 관계의 태도 변화 중 작품에 맞는 표면으로 확인한다.
- 모욕과 압박을 쌓았다면 누가 선택을 목격했고 무엇이 되돌아왔는지 보여 주어 감정적 회수를 만든다.
- 강한 능력과 빠른 독식은 합법적인 상업 판타지다. 성공을 벌주기 위해 무근거 약화, 부작용, 도덕적 대가를 만들지 않는다.

## 현실과 인과

- 제도와 절차는 장면의 저항 또는 주인공의 자원으로 쓴다. 이미 구축된 권력, 뇌물, 협박, 연줄, 법적 권한이 있으면 우회가 가능하다.
- 허구의 범죄, 편견, 착취, 배신과 악인의 승리는 작품 안에서 일어날 수 있다. 불법이나 불쾌감 자체를 creative failure로 판정하지 않는다.
- 실제 Book hard rule과 돈·증거 출처·권한·생존 상태의 모순만 별도 정합성 오류로 막는다.

## 한국어 문체

- 판단은 행동, 질문, 주문, 서명, 이동, 침묵과 상대의 반응으로 보여 준다.
- 설정과 수치를 보고서처럼 늘어놓지 말고 현재 선택과 지급에 필요한 만큼 장면 안에서 쓴다.
- 장면을 끝낸 뒤 의미를 다시 설명하거나 같은 대조문·세 항목 나열을 반복하지 않는다.

## 실패 조건

- 정본에서 필요한 자원·권한·정보 인과가 없는 무상 해결
- 상대와 조연의 확정된 욕망·정보·능력 붕괴
- 실제 지급 없이 영향력과 성장을 선언
- Book에 없는 도덕 교훈, 처벌, 사과, 갱생, 균형을 강제로 추가
